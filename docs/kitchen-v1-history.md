## ครัวกลาง: flow ประจำวัน (เจ้าของสั่ง 2026-10-06)

เจ้าของเล่า flow ทั้งวัน แล้วตอบคำถาม 4 ข้อ (**ห้ามเปลี่ยนโดยไม่ถาม**):
**ยอดที่สาขาสั่ง = อัตโนมัติจากการนับสต๊อกของสาขา** (แอพนับสต๊อกคิดจากอัตราใช้ จ–พฤ/ศ/ส–อา × วันที่ต้องครอบคลุม − ที่นับได้ − ของกำลังมา → ครัวกลางเห็นเอง · ไม่ใช้ safety/max — เจ้าของเคาะ 2026-10-15) ·
**สต๊อกสำรองของที่ผลิต = จำนวนวัน × ยอดส่งเฉลี่ย** (ใส่ตัวเลขตายตัวทับรายเมนูได้) ·
**ค่าใช้จ่ายอื่นหารให้สาขาตามสัดส่วนยอดบิลที่ส่ง** · **ราคาขายสาขา = ต้นทุนวัตถุดิบจริง + %**

- หน้า ☀️ วันนี้ = ขั้นตอน ①–⑥ (`kpStepsHtml`): ① เช็คของ & ผลิตด่วน → ② ส่งของตามสาขา → ③ ผลิตเติมสต๊อก → ④ นับสต๊อก →
  ⑤ สั่งวัตถุดิบ → ⑥ รับของ + บิล · แดชบอร์ดโชว์ขั้นตอนเดียวกัน + รายรับ/รายจ่าย/กำไรเดือนนี้ + เจ้าหนี้ + สต๊อกของผลิต/วัตถุดิบ + มูลค่า
- **สูตร ① (`kpPlan`)** ต่อสูตร: ต้องส่ง = ยอดสาขาที่ยังไม่ได้ส่ง (`brPlan` × ตัวคูณผูกสินค้า) + ออเดอร์ที่กดเองค้างถึงวันนี้ ·
  ด่วน = ต้องส่ง − มี · สำรอง = `safety_qty` หรือ (`safety_days` หรือค่ากลาง) × ยอดส่งเฉลี่ย `avg_days` วัน**ไม่นับวันนี้** (`kpAvgLoad`) ·
  เติม = สำรอง − max(0, มี − ต้องส่ง) · หักใบสั่งผลิตที่ค้าง (`ck_plans` status=plan) · ปัดขึ้นเป็นจำนวนเต็ม (หน่วยชั่ง/ตวงปัด 2 ตำแหน่ง)
- **สั่งผลิต** = `ck_plans` (`kind` urgent/refill + note ⚡/🔄 สำรองไว้ตอนไม่มีคอลัมน์) · บันทึกผลิต: **สั่งผลิต** (วัตถุดิบคิดตาม BOM ×
  สั่ง/yield — ไม่เต็ม batch หารตามสัดส่วน) กับ **ผลิตได้จริง** (ลงสต๊อก + ต้นทุน/หน่วย = ต้นทุนรวม ÷ ได้จริง) · `ck_productions.qty` = ได้จริง,
  `plan_qty` = สั่ง · `ck_recipes.unit_cost` = **ถัวเฉลี่ยกับของเดิมในสต๊อก** · แก้ผลิต = ย้อนของเดิม (`prodReverse`) แล้วลงใหม่ id เดิม
- **ราคาขายสาขา** `recipeSellPrice` = `recipeUnitCost × (1 + markup%)` (`ck_settings.kplan.markup` · ทับรายเมนู `ck_recipes.markup_pct`) —
  **`sell_price` เดิมไม่ใช้แล้ว** · ยอดบิลล็อกไว้ตอนส่ง (`amount_sell`/`total_sell`) แก้ % ทีหลังไม่กระทบบิลเก่า
- **ใบส่งของ** (`brPaintSend`): ติ๊กทีละรายการตอนขึ้นรถ — **ส่งเฉพาะที่ติ๊ก** · ไม่ติ๊ก = ถามก่อนแล้วบันทึก `ck_br_needs.sent=0` ·
  ยอดบิลสด (`brBillPaint`) · เลขบิล `billNoAssign` = `<สาขา>-<ปปดดวว>-<ลำดับวันนั้น>` เช่น `JJRD-261006-1` (ทุกทางที่ส่ง: ยอดนับ/ออเดอร์/ส่งเร็ว)
- **สั่งวัตถุดิบ** (`kpBuyRows`): BOM ของใบสั่งผลิตค้าง + คาดว่าผลิตพรุ่งนี้ (ยอดส่งเฉลี่ย/วัน) + ขั้นต่ำ − มี (ติดลบ = 0) − สั่งไว้แล้ว →
  ใบสั่งซื้อแยกซัพ (`bomPoStep`) → **📤 ส่งไลน์แบบแอพนับสต๊อก** (Edge Function `line-order` ตัวเดียวกัน · `{to,text}` · กลุ่มของซัพ =
  `ck_sups.line_group_id` เลือกจาก `line_groups`) · ส่งแล้ว = สถานะ "สั่งแล้ว" · ไม่ผูกกลุ่ม = เปิด line.me/R/share ให้เลือกเอง ·
  ข้อความใบสั่งเป็นภาษาไทยเสมอ (`poText`)
- **รับของ + บิล**: หัวบิล `ck_bills` (ซัพ เลขบิล วันที่ เครดิต `credit_days` ตั้งต้นจากซัพ · 0 = จ่ายทันที `paid_at`=วันบิล · `due_date`) +
  รายการ = `ck_moves` kind=buy **ref = id บิล** (หน้าใส่ของใช้ `QR` แบบหลายหน่วย โหมด `bill`) · รับตามใบสั่งซื้อ = `billFromPo` ·
  แก้บิล = คืนสต๊อกชุดเดิม (`billReverse`) แล้วลงใหม่ · เปิดบิลเก่ากู้หน่วยเดิมจากหมายเหตุ (`blParseNote`) · ลบบิล = คืนสต๊อก + ใบสั่งซื้อกลับเป็นสั่งแล้ว ·
  ร่างบิลอยู่ `localStorage.jjck_bill_draft` (12 ชม. — ลากหน้าลงไม่หาย) · เจ้าหนี้ = บิลเครดิตที่ `paid_at` ว่าง (`apList` · ปุ่ม ✅ จ่ายแล้ว)
- **บัญชี** (`accData` ใช้ร่วมกับแดชบอร์ด): รายรับ = ยอดบิลส่งสาขา · รายจ่าย = รับของ + ค่าใช้จ่ายอื่น · **หารค่าใช้จ่ายอื่นตามสัดส่วนยอดบิลสาขา**
  (`allocHtml` — คนที่เห็นเฉพาะบางสาขาจะไม่เห็นตารางนี้ เพราะสัดส่วนผิด) · บิลส่งแต่ละสาขา · บิลซัพแยก จ่ายทันที/เครดิต/ค้างจ่าย
- **แก้ไขข้อมูล** (เจ้าของสั่ง "บางส่วนอาจไม่ให้แก้ เดี๋ยวดูอีกที"): `canEditRec(type,d)` — เจ้าของ/ผู้ดูแลระบบแก้ได้เสมอ · คนอื่นตาม
  `ck_settings.editlock` `{bill,prod,send,exp,before}` (ตั้งที่ ⚙️ ตั้งค่า → 🔒 เฉพาะเจ้าของ) · ค่าตั้งต้น = แก้ได้ทุกเรื่อง ไม่ล็อกวันที่ ·
  แก้ได้แล้ว: บิลรับของ · การผลิต · ยกเลิกการส่ง · ค่าใช้จ่าย (✎) — **โค้ดแก้/ลบใหม่ต้องเช็ค `canEditRec`/`editDenied` ด้วย**
- **ต้องรัน `jjmk_kitchen_flow.sql` (branch `sql`)** — ยังไม่รัน = fail-soft: บันทึกช่องอื่นไปก่อน (`insFallback`/`updFallback` · `S.flowSql=false`
  เตือน) · ไม่มี `ck_bills` (`S.billsOk=false`) = รับของได้ แต่ชื่อซัพ/เลขบิลไปอยู่ในหมายเหตุของรายการแทน
- เทส (Playwright + Supabase จำลอง) อยู่ `/tmp` ของ session: ทุกสูตรข้างบน + ติ๊ก/เลขบิล + ไลน์ + บิล/เจ้าหนี้ + ล็อก + ยังไม่รัน SQL + 4 ภาษาที่ 360px

## ครัวกลาง: โหมดใช้ง่าย — ออกแบบให้เด็ก 5 ขวบใช้ได้ (เจ้าของสั่ง 2026-10-06)

> **⚠️ 2026-10-16 เจ้าของสั่ง *"อยากให้ปรับหน้าตาการใช้งานให้เหมือนระบบนับสต๊อก ตอนนี้รู้สึกใช้ยาก"*** — กติกาเมนูมือถือ/หน้างานเต็มจอในหัวข้อนี้**ถูกแทนที่**ด้วยหัวข้อ
> "ครัวกลาง: หน้าตาแบบแอพนับสต๊อก" ข้างล่าง · กติกาที่ยังอยู่: คำง่าย · ปุ่มใหญ่ · 6 ขั้นบนหน้าวันนี้ · ของหัวหน้าพับอยู่ใต้ "📊 ดูสรุปวันนี้"


เจ้าของ: *"มันดูเยอะมาก ใช้ยาก เอาเฉพาะที่ต้องใช้จริง ๆ ออกแบบเพื่อเด็กอายุ 5 ขวบ หรือผู้ใหญ่ที่เพิ่งหัดใช้สมาร์ทโฟน"* —
**กติกานี้ใช้กับทุกหน้าที่พนักงานครัวใช้ทุกวัน แก้/เพิ่มอะไรต้องรักษาไว้**

- หน้า ☀️ วันนี้ = วันที่ตัวใหญ่ + **ปุ่มใหญ่ 6 ขั้นเท่านั้น** (`kpBigStepsHtml` ← `kpSteps`): ⚡ทำของด่วน · 🚚ส่งของให้สาขา · 🍳ทำของเติม · 📋นับของ · 🛒สั่งของ · 📥รับของ
  · ส้ม = ยังต้องทำ · เขียว = เสร็จ · ขั้นแรกที่ยังไม่เสร็จมีป้าย "👉 ทำอันนี้ก่อน" · ของเดิมทั้งหมด (ตัวเลข/ตาราง/การ์ดสาขา) พับอยู่ใต้
  "📊 ดูสรุปวันนี้ (หัวหน้า)" (`<details class="tdmore">` จำสถานะใน `jjck_tdmore`) — **ห้ามย้ายของกลับขึ้นมาบนหน้าวันนี้**
- กดปุ่มขั้นไหน = **หน้างานเต็มจอ ทำทีละเรื่อง** (`openTask` + `tkHead` ปุ่ม "‹ กลับ" ใหญ่ · คลาส `.modal.task` = ตัว 17–40px ปุ่ม ≥52px
  · มือถือเต็มจอ): `taskMake('urgent'|'refill')` → `taskMakeOne` (ต้องทำกี่ + ส่วนผสม + ปุ่ม −/＋ "ทำได้จริงกี่…" + ✓ บันทึก) ·
  `taskSend` → `brSendModal` (แตะตรงไหนของแถวก็ติ๊กได้ `brRowTap` · กลับมารายการสาขาเองหลังส่ง) · `taskBuy` (การ์ดต่อร้าน ปุ่มเดียวส่งไลน์) ·
  `taskRecv` (การ์ดร้านที่สั่งไว้ → บิลเติมรายการให้แล้ว · ＋ รับของอื่น) · บิล/ใส่ของในบิลใช้หน้าแบบเดียวกัน (`taskify`)
- **ทำของ = ยอดที่ระบบคิดคือ "สั่งผลิต"** — กดบันทึกแล้วสร้าง `ck_plans` (kind) ให้เอง แล้วบันทึกผลิตด้วยยอดที่ทำได้จริง (`tmSave` → `produceSave`)
  พนักงานไม่ต้องกด "สั่งผลิต" แยก · หัวหน้ายังใช้ปุ่มสั่งผลิต/แก้จำนวนแบบเดิมได้
- **เปิดไลน์/คัดลอกต้องเกิดตอนกดทันที** (`buySupGo`: ทำข้อความจากรายการบนจอ `buyText` ก่อน แล้วค่อยบันทึกใบสั่ง) — ถ้ารอบันทึกก่อน มือถือบล็อกหน้าต่าง ·
  ร้านที่ไม่ได้ผูกกลุ่มไลน์ = เปิด line.me/R/share แล้วถาม "ส่งให้ … แล้วใช่ไหม?" → ใช่ = สถานะสั่งแล้ว
- เมนู: มือถือมีแค่ **☀️ วันนี้ · 🏠 หน้าหลัก · ☰ เมนู** (`navMenu` = ตารางปุ่มใหญ่ทุกหน้า + ภาษา + ออกจากระบบ) · จอใหญ่แถบข้างโชว์ วันนี้/หน้าหลัก

- คำบนจอ: คำง่ายที่พนักงานพูดกันจริง (ทำของ/ส่งของ/สั่งของ/รับของ/ส่วนผสม/ของสำรอง) — ห้ามใช้ BOM, batch, safety, PO บนหน้าพนักงาน ·
  ข้อความ `sx_*` ครบ 4 ภาษา · ตัวเลขที่ต้องทำ/ต้องส่งตัวใหญ่สีแดง
