> แอพใหม่ **แยกจาก P&L โดยสิ้นเชิง** (ไฟล์เดียว, ตารางชุด `ord_*` ของตัวเอง) · Supabase โปรเจกต์เดียวกัน · เวอร์ชัน 0.1 (2 ก.ย. 2569)
> เว็บ: `https://thananant.github.io/JJ-PnL/jjmk-order.html` (วางไฟล์ทับใน repo เดียวกัน · ย้าย repo ทีหลังได้)

## ติดตั้งครั้งแรก (3 ขั้น)
1. Supabase SQL Editor รัน `sql/jjmk_order_setup.sql` (สร้างตาราง + สิทธิ์) แล้วรัน `sql/jjmk_order_seed.sql` (ซัพ 37 · สินค้า 412 จากโปรแกรมเก่า) — รันซ้ำได้ทั้งคู่
2. วาง `jjmk-order.html` บน GitHub แล้วเปิดเว็บ
3. **ตั้งค่า › ซัพ/รอบส่ง** ไล่ยืนยันวันส่งทุกซัพ (seed ตั้งต้น "ส่งวันถัดไป" ไว้ทุกราย) — พอติ๊ก "ยืนยันแล้ว" ป้ายเตือนจะหาย · PIN ผู้จัดการตั้งต้น **1234** เปลี่ยนที่ ตั้งค่า › ทั่วไป

## สูตรที่ระบบใช้ (หน้าสั่งของโชว์ที่มาทุกตัว)
```
ของที่สั่งวันนี้ มาถึงวัน L1 · ของรอบถัดไปมาถึงวัน L2
สั่ง = ใช้คาดการณ์ทุกคืนใน [L1, L2) + safety − ของที่จะเหลือตอนของมาถึง L1
ของที่จะเหลือตอน L1 = นับล่าสุด + ของที่รับแล้ว/ค้างส่งซึ่งมาถึงก่อน L1 − ใช้คาดการณ์ตั้งแต่วันนับถึงก่อน L1
safety = ใช้เฉลี่ย/คืน × safety_days (ค่ากลาง 1 วัน · ตั้งรายสินค้าได้)
ปัดขึ้นตามลัง (pack_qty) / ขั้นสั่ง (order_step) · หน่วยโล ปัดขึ้นทีละ 0.5
```
- **อัตราใช้/วัน** แยก จ–พฤ / ศ / ส–อา: เริ่มจากค่าในไฟล์เก่า → เมื่อมีข้อมูลนับจริง ≥ 4 จุดต่อกลุ่มวัน ระบบเปลี่ยนไปใช้ค่าที่เรียนรู้เอง (ใช้จริง = นับก่อน + รับเข้า − นับหลัง) · สินค้าที่ไม่มีอัตรา (129 ตัว) ใช้ **max เดิม** ไปก่อน (สั่ง = max − คงเหลือ)
- **รอบสั่ง-ส่ง 4 แบบ**: สั่งได้บางวัน+ส่งอีก N วัน · จับคู่วัน (สั่ง จ ส่ง พ · สั่ง พ ส่ง ศ · สั่ง ศ ส่ง ส · สั่ง ส ส่ง จ) · รอบทุก N วัน · สั่งได้ทุกวัน
- **วันหยุด**: ร้านปิด = ไม่ใช้ ไม่สั่ง ไม่รับ · วันขายดี ×ตัวคูณ · ซัพไม่ส่ง = เลื่อนวันส่ง ระบบสั่งเผื่อให้เองเพราะช่วงต้องพอใช้ยาวขึ้น
- **"เหลือถึงวันส่ง" ติดลบ** = ของจะขาดก่อนของมา → ขึ้น ⚠ ให้หาซื้อแทรก

## โครงข้อมูล (`ord_*`)
`ord_suppliers` (sched jsonb, lead_ok) · `ord_products` (ชื่อ 4 ภาษา, unit, pack_qty/pack_unit, order_step/order_unit, rate {g0,g1,g2}, safety_days, max_old) · `ord_counts` (branch,d,product_id,qty,out_of_stock) · `ord_orders` (status draft/sent/received/cancelled, order_date, deliver_date, line_text) · `ord_order_items` (qty, packs, calc, received_qty) · `ord_holidays` (kind closed/busy/nodeliv) · `ord_settings` (safety_days, pin, min_learn, line_head)

ส่ง LINE อัตโนมัติ (ตอนนี้คัดลอกข้อความ) · ราคาต่อหน่วย/มูลค่าใบสั่ง · ประวัติราคาซัพ · แจ้งเตือนของใกล้ขาดระหว่างวัน · นำเข้า/แก้สินค้าเป็นชุดจาก Excel · ล็อกอินรายคน
