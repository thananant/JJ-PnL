# jj-tests — เทสสูตรทุกระบบ

เดิมเทสหลายร้อยข้อถูกเขียนไว้ใน `/tmp` ของ session แล้วหายทุกครั้งที่ปิด session — ตอนนี้เทสอยู่ใน repo และรันได้ทุก session (hook ติดตั้งของให้)

## รัน

```bash
node tests/unit/run.mjs              # ทุกชุด (~70 วิ · KPI ช้าสุด)
node tests/unit/run.mjs invoice      # เฉพาะชุดที่ชื่อมีคำนี้
VERBOSE=1 node tests/unit/run.mjs hub   # โชว์ทุกข้อที่ผ่าน
```

| ชุด | ตรวจอะไร |
|---|---|
| `invoice` | VAT/ยอดรวม · เงินเป็นตัวอักษรไทย · **ตัวเลข+โฟลเดอร์ในสคริปต์ NAS ตรงกับแอปทุกหลัก** (รัน `inv_nas_sync.py` จริง) · เลขบิล/เรียง/แท็บ ⚠/หมายเหตุ/URL ตัวส่งอีเมล |
| `stock-kitchen` | `orderPlan()` ของนับสต๊อก = `brRow()` ของครัวกลาง 4,000 สถานการณ์สุ่ม (ซัพวันตายตัว/ล่วงหน้า/ทุกวัน/ทุก N วัน + ของกำลังมา + วันขายดี) + กรณีรู้คำตอบ |
| `hub-access` | ใครเห็นแอปไหน (`canOpen`) · บัญชีพร้อมใช้ (`userReady`) · `pwHash` · เทียบเวอร์ชัน |
| `kpi` / `kpi:check` | เทสเดิมใน `kpi/test` |
| `payroll` | เทสเดิมใน `jjmk-payroll/test` (11 ไฟล์) |

## เขียนเทสใหม่ (`tests/unit/<ระบบ>.test.mjs`)

**ห้ามลอกสูตรมาเขียนซ้ำในเทส** — ดึงฟังก์ชันจริงจากไฟล์แอปด้วย `load()` ใน `tests/unit/lib.mjs`:

```js
import { load, py, suite } from './lib.mjs';
const app = load('jjmk-pnl.html', {
  prelude: 'var S={};',            // ค่าคงที่/ตัวแปรที่ฟังก์ชันอ้าง (stub ของ DOM/ฐานข้อมูล)
  vars: ['num'],                   // const/var ที่ต้องเอามาด้วย
  fns: ['hasIncData'],             // ฟังก์ชันที่จะเทส (ชื่อต้องตรงในไฟล์ — เปลี่ยนชื่อแล้วเทสล้มบอกชื่อ)
});
const t = suite('P&L · ลงยอดขาย');
t.eq(app.hasIncData({...}), true, 'คำอธิบายเป็นภาษาไทย');
process.exitCode = t.done() ? 1 : 0;
```

- สูตรที่ต้องตรงกัน 2 ที่ (แอป↔สคริปต์ NAS, นับสต๊อก↔ครัวกลาง, office↔แอปต้นทาง) → เทสแบบเทียบกันด้วยข้อมูลสุ่มที่กำหนดเมล็ด (`py()` เรียกฟังก์ชัน Python จริง)
- เขียนเทสแล้ว **ลองทำให้โค้ดผิดดูว่าเทสจับได้** (แก้ไฟล์ชั่วคราว → รัน → `git checkout <ไฟล์>`)
- เทส UI ที่ต้องใช้เบราว์เซอร์ + Supabase จำลอง ให้ดูแบบใน `tests/mobile/mobile-check.mjs` (`fakeSupabase` · สำเนาไลบรารี CDN ใน `tests/node_modules`)
- ไฟล์ `.sql` ห้ามอยู่ใน main — เทส SQL ไว้ที่ branch `sql`
