📁 โฟลเดอร์ NAS สำหรับเก็บไฟล์ PDF

แนะนำให้ mount/map ไดรฟ์ NAS ไว้ในเครื่องก่อน (เช่น SMB drive ของ Synology) แล้วกดเลือกโฟลเดอร์นั้น — ไฟล์บิลจะถูกบันทึกอัตโนมัติแยกโฟลเดอร์รายเดือน เช่น 2026-09/JJRD1006.pdf
⚠ เบราว์เซอร์นี้ไม่รองรับการบันทึกไฟล์ลงโฟลเดอร์โดยตรง (ต้องใช้ Chrome / Edge บนคอมพิวเตอร์) — ระบบจะดาวน์โหลดไฟล์ PDF ให้แทน แล้วค่อยย้ายไฟล์ไปเก็บใน NAS เอง
โฟลเดอร์ที่เลือก— ยังไม่ได้เลือก —

✉️ ส่งอีเมลหาลูกค้าอัตโนมัติ + ตรวจการตีกลับ

ระบบส่งผ่าน Google Apps Script ของบัญชี Gmail ร้าน (โค้ดส่งให้ในแชท Claude): วางโค้ด → รัน setup() ครั้งเดียว → Deploy เป็น Web app (สิทธิ์ Anyone) → เอา URL ลงท้าย /exec มาใส่ช่องนี้
เมื่อกดออกบิล ระบบจะแนบ PDF ส่งหาลูกค้าทันที และ Apps Script จะตรวจอีเมลตีกลับทุก 5 นาที แล้วอัพเดตสถานะเป็น ส่งถึงแล้ว / ส่งไม่สำเร็จ ให้อัตโนมัติ

✒️ ลายเซ็นผู้รับเงิน (แปะท้ายบิล)

อัพโหลดรูปลายเซ็น (PNG พื้นโปร่งใสจะสวยที่สุด) — เก็บไว้ในเครื่องนี้เท่านั้น ไม่อัพขึ้น Supabase · ถ้าไม่ใส่ บิลจะเว้นช่องว่างให้เซ็นเอง
ยังไม่มีลายเซ็น

ℹ️ วิธีเก็บข้อมูลของระบบนี้

• ข้อมูลบิล (ชื่อลูกค้า รายการ ยอดเงิน) → ตาราง inv_invoices ใน Supabase (ตัวหนังสือล้วน)
• ไฟล์ PDF ใบกำกับภาษี → โฟลเดอร์ NAS ที่เลือกไว้ (แยกโฟลเดอร์รายเดือน)
• ไม่มีไฟล์รูป/PDF ใดๆ ถูกอัพโหลดขึ้น Supabase ทั้งสิ้น
• อีเมลหาลูกค้าส่งจาก Gmail ร้านผ่าน Apps Script (แนบ PDF ต้นฉบับ) + ตรวจการตีกลับอัตโนมัติ
• เปิดดู/พิมพ์บิลย้อนหลังได้ตลอด — ระบบสร้าง PDF สดจากข้อมูลในตาราง
