## นับสต๊อกใหม่ (`jjmk-stockcheck.html`) แทนแอพนับเดิม (เจ้าของสั่ง 2026-10-15)

แอพนับเดิม (`thananant.github.io/jjmk-stock` repo `thananant/jjmk-stock`) ยังใช้ตาราง `products`/`suppliers`/`stock_counts`/`stock_receipts` ชุดเดียวกัน — ของที่เคยทำได้แค่ที่แอพเดิม ย้ายมาแอพใหม่แล้ว:
- **🚚 รอบสั่งซัพ** มีโหมดที่ 3 "สั่งทุก N วัน" (ดูหัวข้อ ครัวกลาง ↔ นับสต๊อก) · ช่อง "ทุก [N] วัน · ส่งหลังสั่ง [lead] วัน" · 💾 เขียน `order_mode`/`cycle_days`/`lead_days`
  · ซัพที่ยังไม่มีในตาราง `suppliers` → `supEnsure()` สร้างให้เอง (เลิกข้อความ "ไปเพิ่มซัพที่แอพนับเดิม")
- **📦 รายการสินค้า**: ➕ เพิ่มสินค้าใหม่ (`newProdOpen`/`newProdSave` — id `p`+16 hex แบบแอพเดิม · เลือกสาขา/แผนก/หน่วย/ซัพ/อัตราใช้ · ชื่อซ้ำในสาขาเดียวกันไม่เพิ่ม · อยู่ในถังขยะ = ถามกู้คืน)
  · 🗑 ถังขยะ + กู้คืน (`deleted_at=null` · ชื่อซ้ำกับของที่ใช้อยู่ไม่กู้) · เปลี่ยนซัพรายสินค้าจากช่องเลือกในแถว (`prodSetSup`) · 🌏 แก้คำแปลรายสินค้า
- **🌏 คำแปลชื่อสินค้าที่คนแก้มือ** (`products.i18n` = `{en,lo,my}` ของแอพเดิม) **ชนะคำแปลกูเกิลเสมอ** (`prodTrSeed`/`prodTrApply` — อ่านทุกสาขารวมตามชื่อ) · แก้ที่แอพใหม่ = เขียน `products.i18n` อย่างเดียว (ทุกสาขาชื่อเดียวกัน · รวมกับค่าเดิม ไม่ล้างภาษาที่ไม่ได้แก้) — **ห้ามเขียนคำแปลมือลง `sc_i18n`** (ลบช่องแล้วจะไม่กลับไปใช้กูเกิล)
- **SQL ที่ต้องรัน 1 ครั้ง** (แปะในแชทแล้ว 2026-10-15): `grant insert on products to anon` + policy insert (เดิม anon มีแค่ select/update → ปุ่มเพิ่มสินค้าขึ้น "ยังไม่มีสิทธิ์เพิ่มสินค้า")
- **บัญชีพนักงานของแอพเดิม (`sc_users`) ไม่ย้าย** — ทุกคนใช้บัญชีกลาง JJ Access อย่างเดียว
- **ถ้าจะเลิกแอพเดิม ห้ามลบ/ปิด**: โปรเจกต์ Supabase · แถวในตาราง `branches` (FK `ON DELETE CASCADE` ลบสต๊อกทั้งสาขา) · LINE token + webhook · Edge Functions + cron (เตือนสั่งของ ฯลฯ) · bucket `product-images` · สคริปต์สำรองบน NAS
  (⚠️ `nas/archive_jjmk.sh` ของ repo เดิมย้าย/ลบ `stock_counts` เก่าตามรอบ — เช็ค Task Scheduler บน NAS ก่อน)
