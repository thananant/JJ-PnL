# 🥜 JJ Allergy — ข้อมูลแพ้อาหาร (`jjmk-allergy.html`)

> เจ้าของสั่ง 2026-10-21: *"ทำระบบเกี่ยวกับการแพ้อาหาร ที่จะใส่รายละเอียดสินค้าแต่ละตัว อาหารแต่ละอย่าง และสามารถค้นหาได้จากสิ่งที่ลูกค้าแพ้"*

## ติดตั้ง
- รัน `jjmk-allergy.sql` (branch `sql`) ครั้งเดียว — รันซ้ำได้ ไม่ลบข้อมูล
- ตั้งสิทธิ์ที่ 🔑 JJ Access → กล่อง JJ Allergy (`pnl_users.apps.allergy`):
  `search` ค้นหา (v) · `items` ข้อมูลสินค้า/อาหาร (v a e d · **e = แก้รายการสิ่งที่แพ้ที่เพิ่มเองได้ด้วย**) · `log` ประวัติ (v)
- ข้อมูลกลางทุกสาขา (เมนูเดียวกัน) — ไม่มี `_br`

## ตาราง
| ตาราง | ใช้ทำอะไร |
|---|---|
| `alg_items` | สินค้า/อาหาร 1 แถว: `name` `kind` `cat` `ingredients` · `contains[]` มีแน่นอน · `may[]` อาจปนเปื้อน · `note` · `checked` ยืนยันแล้ว (+ `checked_by/at`) · `active` เลิกขาย=false · `src` ที่มาตอนนำเข้า (`qr:<id>` / `ck:<id>`) |
| `alg_settings` | key `allergens` = สิ่งที่แพ้ที่เพิ่มเอง `[{k,ic,n,kw[]}]` (รหัส `x_…`) |
| `alg_log` | ประวัติ add/edit/del/import/allergens (เขียนแบบ fail-soft) |

รหัสสิ่งที่แพ้มาตรฐานอยู่ใน `ALG_BUILTIN` (18 อย่าง: กุ้ง/ปู หอย/ปลาหมึก ปลา ไข่ นม ถั่วลิสง ถั่วเปลือกแข็ง ถั่วเหลือง แป้งสาลี งา ขึ้นฉ่าย มัสตาร์ด ซัลไฟต์ ผงชูรส หมู เนื้อวัว แอลกอฮอล์ พริก) — **ห้ามเปลี่ยนรหัส `k` เดิม** (ข้อมูลเก็บเป็นรหัส) เพิ่มใหม่ได้

## กติกา (ความปลอดภัยของลูกค้ามาก่อน)
- ตัวตัดสินเดียว `algClassify(item,codes,words)` ในบล็อก `ALG-CORE` — ห้ามเขียนสูตรซ้ำ · เทส `tests/unit/allergy.test.mjs`
  1. `contains` ตรงสิ่งที่เลือก **หรือ** คำที่พิมพ์เจอในชื่อ/ส่วนผสม/หมายเหตุ → ❌ ห้ามเสิร์ฟ
  2. `may` ตรง → ⚠️ อาจปนเปื้อน
  3. **ยังไม่ติ๊กยืนยัน → ❔ ถามครัวก่อน (ห้ามขึ้น ✅)** — รายการที่นำเข้าใหม่เริ่มที่ ❔ เสมอ
  4. ที่เหลือ → ✅ ทานได้
- คำที่พิมพ์ → `algResolve` นับสิ่งที่แพ้ที่ชื่อ/คำพ้องครอบกันทางใดทางหนึ่งด้วย (เผื่อไว้ก่อน เช่น "มะม่วง" นับถั่วเปลือกแข็งเพราะมะม่วงหิมพานต์) · คำสั้นกว่า 2 ตัวไม่นับ
- โหลดข้อมูลไม่ได้ = แถบแดง "ห้ามใช้ผลบนจอนี้ตอบลูกค้า"
- แก้รายการเขียนแบบ CAS (`updated_at=eq.<ค่าตอนเปิดฟอร์ม>`) — มีคนแก้ก่อน = ไม่ทับ โหลดใหม่ให้แก้อีกรอบ
- เลิกขาย = เอาติ๊ก "ยังขายอยู่" ออก (ลบถาวรต้องมีสิทธิ์ d) · ลบสิ่งที่แพ้ที่เพิ่มเองได้เมื่อไม่มีรายการไหนใช้แล้ว
- นำเข้า: อ่าน `products` (สินค้าในร้านของแอปนับสต๊อก ทุกสาขา · ชื่อเดียวกันรวมเป็นรายการเดียว · `src`=`sc:<ชื่อ>` · ประเภทเดาจาก `cat_label`) + `ck_recipes` + `qr_menu_items` **อย่างเดียว** (ไม่เขียนตารางระบบอื่น) · ข้ามชื่อ/`src` ที่มีแล้ว
- ฟอร์มเก็บร่าง `localStorage.jjalg_draft` (ผูก id + `updated_at`) · แท็บที่เปิด `jjalg_tab` · สิ่งที่เลือกค้นหาเก็บ `sessionStorage` (ปุ่ม 🧹 ล้างเมื่อเปลี่ยนลูกค้า)
- ล็อกอิน: JJ Login + JJ Gate (`APP='allergy'`) · ใบผ่าน `jjalg_sess` (อยู่ใน `spreadSession`/`clearSession` ของหน้าแรก)
