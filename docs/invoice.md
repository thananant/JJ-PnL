## ระบบออกใบกำกับภาษี (JJ Invoice) — ที่เก็บไฟล์ PDF

**ไม่มีไฟล์รูป/PDF ใดๆ ใน Supabase** (เจ้าของสั่งตั้งแต่วันแรก) — **ยกเว้นรูปลายเซ็นผู้รับเงิน 1 รูป** (เจ้าของเลือก 2026-10-15 · ดูหัวข้อ ✒️ ข้างล่าง) — PDF เก็บได้ 3 ทาง:

1. **โฟลเดอร์ NAS ที่ผูกกับเครื่อง** (File System Access API) — เก็บทันทีตอนออกบิล
   แต่ใช้ได้เฉพาะ Chrome/Edge บนคอมที่ map ไดรฟ์ NAS ไว้ · handle เก็บใน IndexedDB
2. **NAS เก็บไฟล์เอง** (2026-09-28 · ทางหลัก) — สคริปต์ `jjmk-invoice/inv_nas_sync.py` รันบน Synology
   ผ่าน Task Scheduler ทุก 5 นาที **แบบเดียวกับ `nas_backup_jjmk.py` ของ P&L (NAS เป็นฝ่ายดึง)**:
   ดึงบิลที่ `nas_path IS NULL` จาก Supabase → สร้าง PDF เอง (fpdf2 + uharfbuzz + ฟอนต์ Prompt) →
   เขียน `<โฟลเดอร์เก็บบิล>/<สาขา>/<MMYYYY>/<BILLNO>.pdf` → PATCH `nas_path` กลับ
   - **โครงโฟลเดอร์ (เจ้าของสั่ง 2026-09-29)**: `JJRD/092026/JJRD1244.pdf` — สาขา = ตัวอักษรหน้าเลขบิล · MMYYYY = เดือน+ปี ค.ศ.
     ตามเวลาไทยของ `issued_at` · ชื่อไฟล์ = เลขบิล (เรียงตามเลขเอง) · **บิลยกเลิกอยู่ `<สาขา>/<MMYYYY>/ยกเลิก/<BILLNO>.pdf`**
   - **1 บิล = 1 ไฟล์** (เจ้าของสั่ง 2026-09-29 แทนการเก็บ `_ฉบับก่อนหน้า`): แก้ไข = เขียนทับใบเดิม · ยกเลิก = ลบใบในโฟลเดอร์เดือน
     แล้วเก็บใบมีตราในโฟลเดอร์ `ยกเลิก` · เรียกคืน = กลับกัน · `remove_other_copies()` ลบ `<BILLNO>.pdf` ที่อื่นทั้งหมดหลังเขียน
     (อีกฝั่งของ `ยกเลิก` · เดือนอื่นของสาขาเดียวกันหลังแก้เลขชน · โครงเก่า `YYYY-MM/` + `_ฉบับก่อนหน้า/`) · ลบเฉพาะชื่อตรงเลขบิลเป๊ะ
     ในโฟลเดอร์ตามโครง ไม่เดินตามลิงก์ลัด · โฟลเดอร์ว่างลบทิ้ง · ข้อมูลจริงอยู่ใน `inv_invoices` สร้าง PDF ใหม่ได้เสมอ
   - ย้ายจากโครงเก่า: ทุกรอบสคริปต์เช็ค (GET ก่อน ไม่เขียนถ้าไม่มี) บิลที่ `nas_path` ยังเป็น `YYYY-MM/...` → ส่งกลับเข้าคิว
     (`requeue_old_layout`) → สร้างในโครงใหม่แล้วลบไฟล์เดิม · **แอป (โฟลเดอร์ที่ผูกกับเครื่อง `saveToNas`) ใช้โครงเดียวกันเป๊ะ**
     (`nasDirs`/`nasRemoveOthers`) — แก้โครงที่ไหนต้องแก้ทั้งสคริปต์และแอป
   - สคริปต์เปิด/เขียน/ลบไฟล์ผ่าน**ที่จับโฟลเดอร์ (dir fd) ที่เปิดทีละชั้นแบบ `O_NOFOLLOW`** (`_sub`) ไม่ใช่ชื่อ path —
     โฟลเดอร์เก็บบิลถูก map ที่เครื่องพนักงาน ใครสลับโฟลเดอร์เป็นลิงก์ลัดระหว่างเช็คกับลงมือ จะพา root ไปลบ/เขียนนอกโฟลเดอร์ได้
   - ฝั่งแอป (โฟลเดอร์ที่ผูกกับเครื่อง): `saveToNas` คืน `{path, left}` — ลบใบเดิมไม่ได้ (มีคนเปิดไฟล์ค้าง) **ห้ามติ๊ก nas_path**
     (NAS ทำงาน = คืนคิวให้ NAS เก็บกวาด · ไม่งั้นเตือนให้ลบเอง) · ปุ่ม 📤 `syncMissingNas` อ่านแถวสดทุกใบ (`freshInv`) +
     ติ๊ก nas_path แบบมีเงื่อนไข (`nas_path is null` + `updated_at` เดิม) ไม่ติด = คืนคิว — รายการเก่าในเครื่องเคยทำให้ลบไฟล์ของ
     บิลระบบเดิมที่เข้ามาแทนเลขหลังแก้เลขชน
   - ติ๊ก `nas_path` หลังเก็บไฟล์จากแอป **ต้องผ่าน `markStored()`** (ทุกทาง: ส่ง · 💾 · 📤) — แก้แค่ `nas_path` + มีเงื่อนไข
     `updated_at` เดิม (แบบ `mark_saved` ของสคริปต์) ไม่ติด = คืนคิว · ลบใบเดิมไม่ได้ = ไม่ติ๊กเลย (คืนคิว + จดประวัติ
     "ลบไฟล์เดิมใน NAS ไม่ได้")
   - คำสั่ง `--check`/`--test` ของสคริปต์ก็เขียนผ่านที่จับโฟลเดอร์แบบ `O_NOFOLLOW` · เทียบไฟล์เดิมด้วย `_same_file()`
     (เปิดแบบไม่บล็อก + เช็คชนิด/ขนาดก่อนอ่าน — กัน FIFO ทำให้สคริปต์ค้างถาวร/ไฟล์ปลอมหลาย GB)
   - **ไม่ต้องเปิดพอร์ต/DDNS/https และไม่มีรหัสลับในเครื่องที่ใช้ออกบิล** — ออกบิลจากมือถือก็เข้า NAS
   - `nas_path` ว่าง = **คิวงานของ NAS** · แอปล้าง `nas_path` เป็น null ตอน **แก้ไขบิล / ยกเลิก / เรียกคืน**
     (`issueOrUpdate` ฝั่งแก้ไข + `setStatus`) เพื่อให้ NAS สร้างไฟล์ใหม่ทับ (บิลยกเลิกจะมีตรา "ยกเลิก")
     · ปุ่ม "🔄 ให้ NAS เก็บใหม่" ในการ์ดบิลก็แค่ล้าง `nas_path`
   - PATCH กลับแบบมีเงื่อนไข `nas_path=is.null&updated_at=eq.<ค่าตอนดึง>` — ถ้าบิลถูกแก้ระหว่างสร้างไฟล์
     จะไม่ติ๊กว่าเก็บแล้ว รอบหน้าสร้างใหม่จากข้อมูลล่าสุด · แก้แค่ช่อง `nas_path` (ไม่แตะ `updated_by`)
   - สคริปต์รายงานตัวทุกรอบที่ `inv_settings`: `nas_sync_last` (เวลา) + `nas_sync_info` (สรุป/ข้อผิดพลาด)
     → แอปโชว์ "สถานะ NAS" ในหน้าตั้งค่า · `nasSyncActive()` = รายงานตัวภายใน 30 นาที (`NAS_SYNC_STALE_MIN`)
     **และ**ไม่ได้ขึ้นต้นด้วย `ผิดพลาด` **และ**เวลาไม่ล้ำอนาคตเกิน 10 นาที → ไม่ดาวน์โหลดไฟล์ให้ตอนออกบิล (NAS เก็บเอง)
     · ไม่เข้าเงื่อนไข = กลับไปดาวน์โหลดเหมือนเดิม (ไฟล์ต้องไม่หายไปไหน — ค่า heartbeat ใครมี anon key ก็ปลอมได้)
   - แอปอ่านสถานะ NAS สด (`refreshNasSync()` — อ่านแค่ 5 คีย์ `nas_sync_last`/`nas_sync_info`/`nas_sync_ver`/`nas_sig_redo`/`signature_at`
     ไม่แตะช่องอื่นในหน้าตั้งค่า · `signature_at` เปลี่ยน = เรียก `loadSignature()` (ไม่รอ) แล้วค่อย `sigRedoCheck()` หลังโหลดเสร็จ ·
     ไม่ได้โหลดใหม่ + `signature_at` ตรงกับในเครื่อง = เรียก `sigRedoCheck()` ท้ายฟังก์ชัน (**ห้ามเรียกตอนลายเซ็นในเครื่องยังเป็นรุ่นเก่า** — ตรวจอิสระเจอว่าใช้สิทธิ์ทำครั้งเดียวไปตอนลายเซ็นถูกลบได้) ·
     วาดหน้าจอพังห้ามขวาง — ห่อ try) ก่อนตัดสินใจทุกครั้งที่ออกบิล + ทุก 5 นาที + ตอนเปิดแท็บตั้งค่า + กลับมาที่แท็บ (`visibilitychange` ≥30 วิ) ·
     **ห้ามใช้ `loadSettings()` ตอนเปิดแท็บ** (เคยทับ URL อีเมลที่ผู้ใช้พิมพ์ค้างไว้)
   - `fmtDT`/`fmtDate` วันที่เสีย = `—` (ไม่ throw) — ค่าเวลาใน `inv_settings` คีย์สาธารณะแก้ได้ เคยทำให้เก็บ PDF ไม่ได้ทั้งแอป
   - คิวของ NAS: ดึง `nas_path=is.null&bill_no=match.^[A-Za-z0-9_-]{1,32}$` เรียง**บิลใหม่ก่อน** (บิลเก่าที่ค้าง/เสียไม่ขวางบิลวันนี้)
     · ถ้า PATCH แบบมีเงื่อนไขไม่ติด (บิลถูกแก้ระหว่างทาง) → `requeue()` ล้าง `nas_path` ให้รอบหน้าสร้างใหม่ทับ
   - ⚠️ **สคริปต์รันด้วย root** — วางสคริปต์ไว้ใน shared folder ที่**เฉพาะ administrators เขียนได้** (เช่น `scripts/inv_sync/`)
     แล้วชี้โฟลเดอร์เก็บบิลด้วย `--base "/volume1/Tax invoice"` (ลำดับ: `--base` > `BASE_DIR` > กฎโฟลเดอร์ `_sync`)
     ห้ามแนะนำให้วางในโฟลเดอร์บิล เพราะโฟลเดอร์บิลถูก map ไว้ที่เครื่องพนักงาน ใครแก้ไฟล์สคริปต์ได้ = รันโค้ดเป็น root บน NAS ได้
     · ร้านติดตั้งครั้งแรก (2026-09-28) ไว้ที่ `/volume1/Tax invoice/_sync` — ขั้นตอนย้ายอยู่ในการ์ดติดตั้งในแอป
     · `write_pdf()` ไม่เดินตาม symlink (เช็คโฟลเดอร์เดือน + เปิด `.part` ด้วย `O_NOFOLLOW|O_EXCL`)
   - ~~เก็บฉบับก่อนหน้า 10 ฉบับใน `_ฉบับก่อนหน้า/`~~ **เลิกแล้ว 2026-09-29** (เจ้าของสั่ง: แก้/ยกเลิก = ลบใบเก่าทิ้ง) ·
     สร้างซ้ำแล้วได้ไฟล์เหมือนเดิมทุกไบต์ = ไม่เขียนซ้ำ (วันที่ในไฟล์ผูกกับ `updated_at` ของบิล)
   - รายการเยอะจนล้น A4 → ขยายหน้าให้ยาวพอ (ไม่ตัดยอดรวม/ลายเซ็นทิ้ง)
   - **ไฟล์สคริปต์อยู่ในรีโปที่ `jjmk-invoice/inv_nas_sync.py`** (GitHub Pages เสิร์ฟคู่แอป) —
     ปุ่ม ⬇ ดาวน์โหลด/📋 คัดลอกในหน้าตั้งค่า `fetch` ไฟล์นี้ · แก้สคริปต์ที่ไฟล์นี้ที่เดียว
   - **หัวบิล `SHOP` ในสคริปต์ต้องตรงกับ `CONFIG.SHOP` ในแอป** และเลย์เอาต์วาดตาม `buildSheetNode()`
     (หน่วย px ของแอป × `K` = pt) — แก้หน้าตาบิลในแอปต้องแก้ `draw_sheet()` ให้ตรงกันด้วย
   - ลายเซ็น: สคริปต์รุ่น `SCRIPT_VER` ≥ 2026-10-15.2 อ่านลายเซ็นจากแอปเอง (ดูหัวข้อ ✒️) · รุ่นเก่ากว่าใช้ `signature.png` ข้างสคริปต์ — ปุ่ม "⬇ ดาวน์โหลดลายเซ็น" แปลงลายเซ็นที่แอปใช้อยู่เป็น `signature.png`
     ให้เอาไปวางข้างสคริปต์รุ่นเก่า
   - ปุ่มล่างสุดของฟอร์มออกบิล/แก้ไขเขียนว่า **"ส่ง"** อย่างเดียว (เจ้าของสั่ง 2026-09-29 · ตัวแปร `ISSUE_LABEL`) —
     เดิมหลังบันทึกการแก้ไข ปุ่มค้างเป็น "บันทึกการแก้ไข + สร้าง PDF ใหม่" ทั้งที่กลับมาหน้าออกบิลใหม่แล้ว
   - คำสั่งของสคริปต์: `--install` (ลง fpdf2+uharfbuzz ใน `_lib` ข้างสคริปต์ · บูต pip เองถ้าไม่มี) ·
     `--check` (บอกโฟลเดอร์ที่ใช้+ที่มา และค่าหน้าสำเนา) · `--test` (ไฟล์ตัวอย่างใน `_test/`) · `--force <เลขบิล>` ·

   - **ตัวเลขใน PDF ของ NAS ต้องตรงกับแอปทุกหลัก**: `js_round` = `Math.round` ของ JS · `round2`/`fmt`/`baht_text`
