📁 โฟลเดอร์ NAS สำหรับเก็บไฟล์ PDF

แนะนำให้ mount/map ไดรฟ์ NAS ไว้ในเครื่องก่อน (เช่น SMB drive ของ Synology) แล้วกดเลือกโฟลเดอร์นั้น — ไฟล์บิลจะถูกบันทึกอัตโนมัติแยกโฟลเดอร์ สาขา/เดือนปี เช่น JJRD/092026/JJRD1006.pdf (บิลยกเลิกอยู่ในโฟลเดอร์ย่อย ยกเลิก)
⚠ เบราว์เซอร์นี้ไม่รองรับการบันทึกไฟล์ลงโฟลเดอร์โดยตรง (ต้องใช้ Chrome / Edge บนคอมพิวเตอร์) — ระบบจะดาวน์โหลดไฟล์ PDF ให้แทน แล้วค่อยย้ายไฟล์ไปเก็บใน NAS เอง
โฟลเดอร์ที่เลือก— ยังไม่ได้เลือก —

🖥 NAS เก็บไฟล์ให้เอง — ออกบิลจากมือถือ/เครื่องไหนก็เข้า NAS อัตโนมัติ

ให้ NAS รันสคริปต์ทุก 5 นาที (Task Scheduler แบบเดียวกับสคริปต์สำรองข้อมูลของ P&L): NAS ดึงข้อมูลบิลที่ยังไม่มีไฟล์จาก Supabase มาสร้าง PDF แล้วเก็บลงโฟลเดอร์เอง แยกโฟลเดอร์ สาขา/เดือนปี เช่น JJRD/092026/JJRD1244.pdf (ชื่อไฟล์ = เลขบิล เรียงตามเลขเอง) · ไม่ต้องเปิดพอร์ต ไม่ต้องตั้งอะไรในเครื่องที่ใช้ออกบิล · บิลที่แก้ไข = ลบใบเดิมทิ้งแล้วเก็บใบใหม่ · บิลที่ยกเลิก = ลบใบเดิม แล้วเก็บใบที่มีตรา "ยกเลิก" ในโฟลเดอร์ย่อย ยกเลิก ของเดือนนั้น · เรียกคืน = ย้ายกลับ (NAS ทำให้เอง)
สถานะ NAS—
บิลที่รอเก็บไฟล์ลง NAS—
📋 ขั้นตอนติดตั้งบน Synology (ทำครั้งเดียว ~10 นาที) — กดเพื่อดู
  1. กด ⬇ ดาวน์โหลด inv_nas_sync.py ข้างล่าง (ถ้ามีลายเซ็นในเครื่องนี้ กด ⬇ ดาวน์โหลดลายเซ็น ด้วย)
  2. 🔒 เก็บสคริปต์ไว้ในโฟลเดอร์ที่พนักงานแก้ไม่ได้ — Control Panel → Shared Folder → สร้าง ชื่อ scripts → หน้าสิทธิ์: administrators = อ่าน/เขียน · คนอื่น/กลุ่ม users = ไม่มีสิทธิ์ (ถ้ามีโฟลเดอร์แบบนี้อยู่แล้ว เช่น ที่เก็บสคริปต์สำรองข้อมูลของ P&L ใช้อันนั้นได้เลย · สคริปต์รันด้วย root — ถ้าวางไว้ในโฟลเดอร์บิลที่เครื่องพนักงาน map ไว้ ใครแก้ไฟล์ได้ = สั่งงาน NAS ได้ทั้งเครื่อง)
  3. File Station → scripts → สร้างโฟลเดอร์ inv_sync → อัพโหลด inv_nas_sync.py (และ signature.png) ลงไป (ดูพาธเต็มได้ที่ คลิกขวา → คุณสมบัติ · ตัวอย่างข้างล่างใช้ /volume1/scripts/inv_sync และโฟลเดอร์เก็บบิล /volume1/Tax invoice — เปลี่ยนให้ตรงของจริง)
  4. Control Panel → Task Scheduler → สร้าง → Scheduled Task → User-defined script · ชื่อ ติดตั้งตัวเก็บบิล · ผู้ใช้ root · แท็บกำหนดเวลา: ทำงานในวันต่อไปนี้ (ครั้งเดียว) · แท็บการตั้งค่างาน ช่อง Run command:
    python3 "/volume1/scripts/inv_sync/inv_nas_sync.py" --base "/volume1/Tax invoice" --install
    กด OK → เลือก task นี้แล้วกด Run → รอ 2-3 นาที → เปิดไฟล์ inv_sync/inv_nas_sync.log ต้องเห็น พร้อมใช้งาน ✅
  5. สร้างอีก task: User-defined script · ชื่อ เก็บใบกำกับภาษีลง NAS · ผู้ใช้ root · แท็บกำหนดเวลา: ทำซ้ำ รายวัน · เวลาเริ่มต้น 00:00 · ติ๊ก ทำงานต่อภายในวันเดียวกัน → ทำซ้ำ ทุก 5 นาที · การใช้งานครั้งล่าสุด 23:55 (อันล่างสุด) · Run command:
    python3 "/volume1/scripts/inv_sync/inv_nas_sync.py" --base "/volume1/Tax invoice"
  6. กลับมาดูหน้านี้ ภายใน 5 นาที "สถานะ NAS" จะขึ้น 🟢 และบิลที่รอจะทยอยเข้า NAS (อยากเห็นหน้าตาไฟล์ก่อน: รันคำสั่งในข้อ 4 ต่อท้ายด้วย --test ได้ไฟล์ตัวอย่างในโฟลเดอร์ _test ของโฟลเดอร์เก็บบิล)
  7. เคยติดตั้งแบบเก่าไว้ในโฟลเดอร์ _sync ของโฟลเดอร์บิล: File Station ย้ายโฟลเดอร์ _sync ทั้งโฟลเดอร์ไปไว้ใน scripts (ไลบรารี/ฟอนต์ย้ายตามไปด้วย ไม่ต้อง --install ใหม่) แล้วแก้ Run command ของ task ทุก 5 นาทีเป็น python3 "/volume1/scripts/_sync/inv_nas_sync.py" --base "/volume1/Tax invoice"
ลายเซ็นเก็บอยู่ในเบราว์เซอร์ของแต่ละเครื่อง NAS มองไม่เห็น — ต้องวาง signature.png ไว้โฟลเดอร์เดียวกับสคริปต์ด้วย บิลที่ NAS สร้างถึงจะมีลายเซ็น (ไม่มี = เว้นช่องให้เซ็นเอง)
ใช้ได้เฉพาะคอมที่เลือกโฟลเดอร์ NAS ไว้ในการ์ดข้างบน — ถ้า NAS เก็บให้เองอยู่แล้วไม่ต้องกด

✉️ ส่งอีเมลหาลูกค้าอัตโนมัติ + ตรวจการตีกลับ

ส่งจาก Gmail ของร้าน ผ่าน Google Apps Script (ฟรี ไม่ต้องใช้บัตร ไม่ต้องบอกรหัสผ่านใคร): เมื่อกดออกบิล ระบบแนบ PDF ส่งหาลูกค้าทันที แล้วตรวจอีเมลตีกลับทุก 5 นาที อัพเดตสถานะเป็น ส่งถึงแล้ว / ส่งไม่สำเร็จ ให้เอง · ตั้งครั้งเดียว ใช้ได้ทุกเครื่อง
📋 ขั้นตอนตั้งค่าตัวส่งอีเมล (ทำครั้งเดียว ~3 นาที) — กดเพื่อดู
  1. เปิด script.new ด้วยบัญชี Gmail ของร้าน (บัญชีที่จะใช้เป็นผู้ส่ง)
  2. ลบโค้ดตัวอย่างในหน้านั้นออกให้หมด → กดปุ่ม คัดลอกโค้ด ข้างล่างนี้ แล้ววาง (Ctrl+V) ลงไป → กดบันทึก 💾
  3. เลือกฟังก์ชัน setup ด้านบน → กด Run ▶ → กด Review permissions → เลือกบัญชีร้าน → Advanced → Go to (unsafe) → Allow (หน้าเตือนนี้ปกติ เพราะเป็นสคริปต์ที่เราเขียนเอง)
  4. กด Deploy (มุมขวาบน) → New deployment → ไอคอน ⚙ เลือก Web app → ตั้ง Execute as: Me · Who has access: Anyone → Deploy
  5. คัดลอก Web app URL (ลงท้าย /exec) มาวางในช่องข้างล่าง → กด บันทึก URL → กด ทดสอบส่งอีเมล เช็คว่าเข้ากล่องจดหมายจริง
เปิด script.new ↗
โควตาส่งฟรีของ Gmail ทั่วไป = 100 ฉบับ/วัน (บัญชี Google Workspace = 1,500 ฉบับ/วัน)

📥 นำเข้าบิลจากระบบเดิม (ไฟล์ Excel)

ไฟล์ที่ export จากชีต Invoices ของระบบออกใบกำกับภาษีเดิม (Google Sheet / Apps Script) · นำเข้าแล้วค้นหา ดู พิมพ์ ส่งอีเมลซ้ำ ได้เหมือนบิลที่ออกจากแอปนี้ · NAS สร้างไฟล์ PDF ของบิลเก่าเก็บให้ครบ · เลขบิลของแอปนี้จะต่อจากเลขล่าสุดของระบบเดิมให้เอง · บิลที่มีเลขนี้ในระบบแล้วจะข้าม ไม่เขียนทับ
⚠️ ปิดระบบเดิมก่อนนำเข้า (ให้ทุกคนออกบิลจากแอปนี้แทน) แล้วค่อย export ไฟล์ล่าสุดมา — ถ้าสองระบบออกบิลพร้อมกัน จะได้เลขเดียวกันคนละลูกค้า · นำเข้าซ้ำได้ ใบที่มีแล้วจะข้าม · ใช้ไฟล์ .xlsx (Google Sheets: ไฟล์ → ดาวน์โหลด → Microsoft Excel) — ไฟล์ CSV ภาษาไทยจะเพี้ยน
🔒 ไฟล์ถูกอ่านในเครื่องนี้เท่านั้น — ไม่อัพโหลดไฟล์ขึ้นที่ไหน เก็บแค่ข้อมูลบิล (ตัวหนังสือ) ลงตารางเดียวกับบิลใหม่

ℹ️ วิธีเก็บข้อมูลของระบบนี้

• ข้อมูลบิล (ชื่อลูกค้า รายการ ยอดเงิน) → ตาราง inv_invoices ใน Supabase (ตัวหนังสือล้วน)
• ไฟล์ PDF ใบกำกับภาษี → NAS แยกโฟลเดอร์ สาขา/เดือนปี (บิลยกเลิกอยู่ในโฟลเดอร์ย่อย ยกเลิก)
• ไม่มีไฟล์รูป/PDF ใดๆ ถูกอัพโหลดขึ้น Supabase ทั้งสิ้น
• อีเมลหาลูกค้าส่งจาก Gmail ร้านผ่าน Apps Script (แนบ PDF ต้นฉบับ) + ตรวจการตีกลับอัตโนมัติ
• เปิดดู/พิมพ์บิลย้อนหลังได้ตลอด — ระบบสร้าง PDF สดจากข้อมูลในตาราง
