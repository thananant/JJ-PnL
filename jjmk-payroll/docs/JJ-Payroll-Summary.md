## 3. กฎเงินเดือน (ตามที่เจ้าของสั่ง)

**งวด**: 26 เดือนก่อน → 25 เดือนนี้ · จ่ายวันที่ 5 เดือนถัดไป · จุดตัดวัน 06:00 (สแกนก่อนตี 6 = กะเมื่อวาน)

**ค่าแรง**
- รายวัน = วันทำงาน × อัตรา · รายเดือน = เหมาเดือน (÷30 เป็นค่าแรงวัน) · รายชั่วโมง = ชม.เต็ม × อัตรา · นับชั่วโมง = เป้า ชม./วัน
- พนักงานใหม่ default รายเดือน 12,000 · เริ่มงานหลัง 26 หรือออกก่อน 25 → งวดนั้นคิดรายวัน (วัน × เงินเดือน÷30)
- OT รายวัน: อัตรา = ค่าแรงวัน ÷ (ชั่วโมงกะ − 1 ชม.พัก) เช่น 12,000 กะ 9 ชม. → 400÷8 = 50 บาท/ชม.

**รายการหักอัตโนมัติ** (แก้ยอดรายงวดได้ถ้าหักผิด)
- สาย/ออกก่อน: นาทีละ 1.5 บาท (เกิน grace 5 นาที) · ลืมตอกบัตร: ครั้งละ 200
- หยุดวันห้ามหยุด (ศ ส อา + วันหยุดพิเศษ): หัก **2 เท่าค่าแรงวัน** (เริ่มงวด ส.ค. 2569) · ยกเว้น OFFICE / Manager / คนมีวันหยุดประจำ / รายชั่วโมง
- เบิกกลางเดือน · เงินประกัน 500 · ผ่อนเงินยืม · ผ่อน MOU · ประกันสังคม 5%

**รายรับเพิ่ม**
- เบี้ยไม่หยุด (ไม่ใช้สิทธิ์วันหยุด) วันละ 400 · เบี้ยวันหยุดพิเศษ (มาทำงาน ไม่สาย ไม่ลืมตอก) ตามตัวคูณ
- **ทิปประจำงวด**: ใส่ยอดรวมต่อสาขา หารเท่ากันทุกคนที่มีวันทำงาน (เลือกคนเองได้) เศษสตางค์ปัดลง · คนพ้นสภาพไม่ได้และไม่นับตัวหาร

**เบิกกลางเดือน**: เพดาน 3,000 (Manager 5,000) หรือ 50% ของค่าแรงที่ทำมาถึงวันเบิก · หักคืนตอนจ่ายเงินเดือน · เงินยืมโหมด mid หักจากยอดโอนเบิก (โอนสุทธิ = เบิก − ผ่อน)

**คนพ้นสภาพ**: ยังขึ้นในสรุปเงินเดือน/สลิป/ไฟล์โอน ถ้ามีวันทำงานในงวด (จ่ายงวดสุดท้ายได้) · ต้องกรอกวันสิ้นสุดงาน ไม่งั้นรายเดือนได้เต็มเดือน + โดนปรับหยุดวันห้ามหยุดหลังออก · ไม่ขึ้นหน้าวันนี้/เบิก/ทิป

## 8. จุดเชื่อมกับ JJ-PnL (ข้อเสนอ)

ตัวเลขที่ Payroll คำนวณได้และ PnL น่าจะต้องใช้ — ทั้งหมดคิดสดจาก `calcPay(emp, period)` แยกสาขา/แผนกได้:

| ตัวเลข | มาจาก | หมายเหตุ |
|---|---|---|
| ค่าแรงรวมต่อสาขาต่องวด (Labor cost) | `p.base + p.addSum` ของทุกคนในสาขา | งวด 26–25 ไม่ตรงเดือนปฏิทิน — ต้องตกลงว่า PnL จะใช้งวดเงินเดือนหรือแบ่งตามวัน |
| ค่าแรงครัวกลาง (JJCK) แยกต่างหาก | สาขา JJCK | ครัวกลางผลิตให้ 2 สาขา อาจต้องปันส่วนใน PnL |
| OT / เบี้ยพิเศษ / ทิป | `adjustments` + `p.holiBonus` + `p.tip` | ทิปเป็นเงินลูกค้า ไม่ใช่ต้นทุนร้าน (แต่ผ่านสลิป) |
| เงินสมทบประกันสังคมฝั่งนายจ้าง | `p.sso.employer` (เท่ากับที่หักพนักงาน) | ต้นทุนที่ไม่อยู่ในสลิป — PnL ต้องบวกเพิ่ม |
| เบิกกลางเดือน | `advances` | เป็นการจ่ายล่วงหน้า ไม่ใช่ต้นทุนเพิ่ม (กระทบกระแสเงินสดวันที่ 15) |
| เงินยืม / MOU / เงินประกัน | `loans` `mou_loans` `deposit_*` | เป็นลูกหนี้/เจ้าหนี้พนักงาน ไม่ใช่ค่าใช้จ่าย |
| จำนวนคน / วันทำงาน / ชั่วโมง ต่อสาขา | `empShiftsInPeriod` | ใช้คิด labor hours ต่อยอดขาย |

ทางเทคนิค: PnL อ่านจาก Supabase โปรเจกต์เดียวกันได้เลย (publishable key ฝังใน frontend ได้ ทุกตาราง allow-all) หรือให้ Payroll ส่ง Export Excel ต่องวด (ปุ่ม 📤 มีคอลัมน์ ค่าแรง/เพิ่ม/หัก/สุทธิ รายคน) — ถ้าจะให้แม่น แนะนำทำ endpoint สรุปต่อสาขาต่องวดใน Worker แล้ว PnL ดึงไปใช้ จะได้ไม่ต้องคำนวณซ้ำสองที่
